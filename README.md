# SalesDrive — обробка замовлень (окремий сайт)

Повноцінний сайт (Node.js + PostgreSQL) для того самого, що робив попередній
додаток на Google Apps Script: вхід/реєстрація, завантаження замовлень зі
SalesDrive за статусом, друк і об'єднання декількох ТТН Нової пошти в один
PDF (формат — повна накладна або наклейка 100х100), сортування/фільтр/пошук,
завершення замовлень (статус назад у SalesDrive + видалення зі списку).

Дані зберігаються в базі даних (Supabase), а не в Google Таблиці — сайт живе
постійно за власною адресою, а не тільки поки відкрита вкладка.

## Технології

- Backend: Node.js + Express
- База даних: PostgreSQL (безкоштовний план Supabase)
- Хостинг: Render.com (безкоштовний план)

## Крок 1. Створити базу даних (Supabase)

1. Зареєструйтесь на [supabase.com](https://supabase.com) (можна через Google)
2. "New Project" → задайте назву й **надійний пароль бази даних** (збережіть його!)
3. Дочекайтесь створення проєкту (1-2 хв)
4. Зліва: **Project Settings → Database → Connection string → URI**
5. Скопіюйте рядок виду:
   `postgresql://postgres:[ВАШ-ПАРОЛЬ]@db.xxxxxxxxxxxx.supabase.co:5432/postgres`
   (підставте свій пароль замість `[ВАШ-ПАРОЛЬ]`) — це і є `DATABASE_URL`

## Крок 2. Викласти код на GitHub

1. Створіть новий репозиторій на [github.com](https://github.com) (наприклад `ttn-site`)
2. Завантажте туди всі файли цієї папки (через "Add file → Upload files" у браузері —
   найпростіше, не потрібен git у командному рядку)

## Крок 3. Розгорнути на Render

1. Зареєструйтесь на [render.com](https://render.com) (можна через GitHub)
2. **New → Web Service** → підключіть щойно створений репозиторій
3. Render сам підхопить налаштування з `render.yaml`, якщо запитає — вкажіть:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** Free
4. У розділі **Environment** додайте змінні (значення — свої):
   - `DATABASE_URL` — рядок з Кроку 1
   - `JWT_SECRET` — будь-який довгий випадковий рядок (напр. згенерований на randomkeygen.com)
   - `SALESDRIVE_DOMAIN` — `https://ekvator.salesdrive.me`
   - `SALESDRIVE_FORM_API_KEY` — ваш ключ з SalesDrive (Установки → Інші сервіси → API)
   - `SD_PULL_STATUS` — `3`
   - `SD_DONE_STATUS` — `11`
   - `NOVAPOSHTA_API_KEY` — ваш ключ Нової пошти
5. Натисніть **Create Web Service** — почнеться перше розгортання (2-5 хв)

## Крок 4. Створити таблиці в базі даних

Після першого успішного розгортання, у Render: **Shell** (вкладка зверху) →
виконайте команду:
```
npm run migrate
```
Це створить потрібні таблиці в базі даних Supabase. Робиться один раз.

## Крок 5. Готово

Відкрийте адресу вашого сервісу (показана вгорі сторінки Render, виду
`https://ttn-fulfillment-site.onrender.com`) — там сторінка входу/реєстрації.
Зареєструйте перший акаунт і починайте користуватись.

Ця адреса — постійна, працює завжди, її можна зберегти в закладки або
вставити на Google Сайт через "Вставка → Вбудувати → За URL-адресою".

## Примітка про безкоштовний план Render

Безкоштовний сервіс "засинає" після ~15 хв без відвідувань і "прокидається"
за 30-50 секунд при наступному відкритті (перший запит буде повільним, далі
все швидко). Це нормально й безкоштовно; якщо потрібна миттєва доступність
24/7 — на Render є платний план від $7/міс, який не засинає.

## Локальний запуск (необов'язково, для розробки)

```
npm install
cp .env.example .env      # заповнити реальними значеннями
npm run migrate
npm start
```
Сайт буде доступний на http://localhost:3000
